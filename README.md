# dubby-downloaders

Release host for the video downloaders that [Dubby](https://github.com/nxkhang183/Dubby) installs in-app. The app reads the `latest` release (`downloader-versions.json`, `checksums.sha256` and one binary per tool/platform).

Contents, as collected by [buxuku/smartsub-downloaders](https://github.com/buxuku/smartsub-downloaders):

- [yt-dlp](https://github.com/yt-dlp/yt-dlp): official release binaries, released into the public domain under the [Unlicense](https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE).
- [lux](https://github.com/iawia002/lux): built from source, [MIT](https://github.com/iawia002/lux/blob/master/LICENSE).
